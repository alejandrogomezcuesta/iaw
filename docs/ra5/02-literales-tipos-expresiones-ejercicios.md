# Ejercicios: `print` y literales en PHP

En estos ejercicios practicarás cómo mostrar información con `print`, reconocer
literales y evaluar expresiones aritméticas en PHP.

## Antes de empezar

Guarda cada ejercicio en un fichero con extensión `.php`, por ejemplo,
`ejercicio1.php`. Un programa PHP comienza con `<?php`; las instrucciones
terminan con punto y coma (`;`). Para mostrar texto, escríbelo entre comillas:

```php linenums="1"
<?php
print("¡Hola!");
```

Puedes ejecutar el fichero desde una terminal si PHP está instalado:

```bash
php ejercicio1.php
```

Un **literal** es un valor escrito directamente en el código. Por ejemplo,
`"Hola"` es un literal de texto, `42` es un literal entero y `3.14` es un
literal decimal. PHP también permite mostrar el resultado de una expresión
aritmética directamente con `print`.
